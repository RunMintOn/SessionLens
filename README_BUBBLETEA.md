# Bubble Tea Session Manager

Minimal Bubble Tea TUI starter for agent session management.

## Run

```bash
go run ./cmd/session-manager
```

## Controls

- `↑` / `k` - Move cursor up
- `↓` / `j` - Move cursor down
- `q` - Quit

## Features

- Title header with styling
- Demo session list with colored source badges (OpenCode, Claude, Qwen)
- Basic key navigation
- Quit functionality
