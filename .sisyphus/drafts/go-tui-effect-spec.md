## 🎮 2. 交互效果详解

### 2.1 键盘导航效果

#### 场景：向下移动光标

**初始状态**:
```
▼ ~/project-a (2)
  > 会话 1 [Claude]     ← 当前选中
  · 会话 2 [OpenCode]

▶ ~/project-b (1)
```

**用户操作**: 按 `↓` 或 `j`

**效果**:
```
▼ ~/project-a (2)
  · 会话 1 [Claude]
  > 会话 2 [OpenCode]   ← 光标移动到这里

▶ ~/project-b (1)
```

**视觉反馈**:
- 光标从 `>` 变为 `·`
- 新位置从 `·` 变为 `>`
- 无延迟，即时响应

---

#### 场景：项目路径不可选中

**设计说明**:
- 项目路径是**分组标题**，不可选中
- 光标只能在会话节点间移动
- 项目路径仅提供视觉分组

**初始状态**:
```
~/project-a
  · 会话 1 [Claude]
  > 会话 2 [OpenCode]  ← 光标在会话上

~/project-b
  · 会话 3 [Qwen]
```

**用户操作**: 按 `↑` 或 `k` 向上移动

**效果**:
```
~/project-a
  > 会话 1 [Claude]    ← 光标移动到上一个会话

~/project-b
  · 会话 3 [Qwen]
```

**边界情况**: 如果光标在项目的**第一个会话**上按 `↑`:
```
// 光标移动到上一个项目的最后一个会话
~/project-a
  > 会话 1 [Claude]    ← 光标移动到这里

~/previous-project
  · 上一个会话 [Claude]
```

## 🎨 3. 视觉状态详解

### 3.1 项目节点状态

| 状态 | 显示 | 说明 |
|------|------|------|
| **展开 + 选中** | `> ▼ ~/project (N)` | 光标在项目上，展开状态 |
| **展开 + 未选中** | `  ▼ ~/project (N)` | 普通展开状态 |
| **折叠 + 选中** | `> ▶ ~/project (N)` | 光标在项目上，折叠状态 |
| **折叠 + 未选中** | `  ▶ ~/project (N)` | 普通折叠状态 |

### 3.2 会话节点状态

| 状态 | 显示 | 说明 |
|------|------|------|
| **选中 + 收藏** | `> ★ 会话名 [来源]` | 光标在收藏的会话上 |
| **选中 + 未收藏** | `> · 会话名 [来源]` | 光标在未收藏的会话上 |
| **未选中 + 收藏** | `  ★ 会话名 [来源]` | 普通收藏会话 |
| **未选中 + 未收藏** | `  · 会话名 [来源]` | 普通会话 |

### 3.3 过滤按钮状态

| 状态 | 显示 | 说明 |
|------|------|------|
| **激活** | `[全部]` (紫色背景) | 当前过滤条件 |
| **未激活** | `[Claude]` (灰色背景) | 非当前过滤 |
| **Hover** | `[Claude]` (浅灰背景) | 鼠标悬停（可选） |

## 🎹 9. 快捷键大全

| 按键 | 功能 | 场景 | 备注 |
|------|------|------|------|
| `↑` / `k` | 向上移动 | 主界面/隐藏列表 | 在会话间移动 |
| `↓` / `j` | 向下移动 | 主界面/隐藏列表 | 在会话间移动 |
| `Enter` | 进入/恢复 | 主界面 | 在会话上：恢复会话；在项目路径上：无效果 |
| `c` | 收藏/取消收藏 | 主界面 | 切换当前会话的收藏状态 |
| `h` | 隐藏会话 | 主界面 | 将当前会话移到隐藏列表 |
| `H` | 查看隐藏列表 | 主界面 | 打开隐藏列表覆盖层 |
| `r` | 恢复会话 | 隐藏列表 | 恢复选中的隐藏会话 |
| `a` | 全部恢复 | 隐藏列表 | 恢复所有隐藏会话 |
| `←` / `h` | 上一个过滤 | 过滤按钮 | 切换过滤条件（待实现） |
| `→` / `l` | 下一个过滤 | 过滤按钮 | 切换过滤条件（待实现） |
| `1` | 全部 | 主界面 | 显示所有会话 |
| `2` | Claude | 主界面 | 只显示 Claude 会话 |
| `3` | OpenCode | 主界面 | 只显示 OpenCode 会话 |
| `4` | Qwen | 主界面 | 只显示 Qwen 会话 |
| `/` | 搜索 | 主界面 | 打开搜索框 |
| `Esc` | 退出搜索/隐藏列表 | 搜索/隐藏列表 | 返回主界面 |
| `q` | 退出程序 | 主界面 | 关闭程序 |
| `r` | 刷新 | 主界面 | 重新扫描会话（待实现） |
