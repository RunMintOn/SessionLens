# Known Issues

更新时间：2026-02-20

## 1. 选中高亮在下滑后消失

- 现象：首页第一屏时，蓝色选中高亮显示正常；继续向下滚动后，选中高亮会消失。
- 影响：用户无法稳定定位当前选中项，导航体验受影响。
- 当前状态：待排查（疑似与滚动窗口渲染/选中行映射有关）。

## 2. Claude Code 会话聚合逻辑仍有问题

- 现象：Claude Code 的分组或会话展示逻辑仍不稳定，和预期的“按真实项目路径聚合”存在偏差。
- 影响：同一项目下会话可能仍未正确合并，或存在异常显示。
- 当前状态：待继续探索（需要进一步验证 Claude 原始数据结构与解析规则）。
